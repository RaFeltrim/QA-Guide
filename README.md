## About This Repository

This repository contains a complete learning path for Quality Assurance professionals at all levels:
- **Intern Level**: Manual testing, bug reporting, basic documentation
- **Junior Level**: Unit testing, basic automation, CI fundamentals
- **Mid-Level/Pleno**: Advanced automation, E2E testing, performance testing
- **Senior Level**: Strategic QA, team leadership, process optimization

## Features

- 📚 **Comprehensive Learning Paths** - Structured content for all skill levels
- 💻 **Hands-On Exercises** - Practical examples and real-world scenarios
