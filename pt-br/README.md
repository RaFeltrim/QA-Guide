## Sobre Este Repositório

Este repositório contém um caminho de aprendizado completo para profissionais de Garantia de Qualidade em todos os níveis:
- **Nível Estagiário**: Teste manual, reportagem de bugs, documentação básica
- **Nível Júnior**: Teste unitário, automação básica, fundamentos de CI
- **Nível Pleno**: Automação avançada, teste E2E, teste de performance
- **Nível Sênior**: QA estratégico, liderança de equipe, otimização de processos

## Recursos

- 📚 **Caminhos de Aprendizado Abrangentes** - Conteúdo estruturado para todos os níveis de habilidade
- 💻 **Exercícios Práticos** - Exemplos práticos e cenários do mundo real
- 🛠️ **Frameworks de Automação** - Cypress, Jest, Pytest, k6, Postman, JMeter
- ⚙️ **Integração CI/CD** - Pipelines do GitHub Actions para testes automatizados
- 📊 **Teste de Performance** - Técnicas de teste de carga e estresse
- 🔧 **Melhores Práticas** - Práticas padrão da indústria de QA e modelos
