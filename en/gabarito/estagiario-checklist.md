# Checklist Rápido — Estagiário

Use esta checklist antes de enviar qualquer entrega ou bug report.

- [ ] Caso de teste com ID e passos claros
- [ ] Pré-condições documentadas
- [ ] Dados de teste/fixtures indicados
- [ ] 2 evidências (screenshots) anexadas para cada execução
- [ ] Logs/Console anexados quando houver erro
- [ ] Bug report preenchido com passos e evidências (se aplicável)
- [ ] Severidade e reprodutibilidade indicadas
- [ ] Dados sensíveis removidos das evidências
