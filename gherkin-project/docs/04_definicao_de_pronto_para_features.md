# 04 — Definição de Pronto (DoD) para features

Uma feature está pronta quando:

- Revisada pelo PO/Analista de Negócio.
- Cobertura mínima: 2 happy paths, 2 negativos, 1 esquema de exemplos quando aplicável.
- Steps comportamentais e legíveis.
- Implementação mínima de steps disponível ou backlog com prioridade.
- Suíte executa localmente e em CI (ou justificativa para flakiness).
